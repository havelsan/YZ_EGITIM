Day 1 — Core AI + Machine Learning Foundations (Engineer-Oriented)

1. AI landscape for engineers 
   AI vs ML vs Deep Learning vs Generative AI
   Regression vs Classification vs Clustering vs Generative
   Where classical software ends and ML systems begin
   Why ML is “data + optimization + models”
  
  
2. How ML systems actually work
   Dataset → training → model → inference pipeline  ( Standard Worklfow for Training/Evaluating an AI model : Data Collection, Cleaning, Feature Extraction, splitting Data , Batch Size determination, Training, Testing, Evaluation.)
   Train/test split, overfitting (intuition, not math-heavy)
   Loss function intuition
   Feature vs representation learning
   ML Model Evaluation : False Positive, Precision, Recall, Accuracy, Cross Correlation 
   
3. Core ML types (practical framing)
   Supervised learning (classification/regression)
   Unsupervised learning (clustering, embeddings idea)
   Reinforcement learning (high-level only)
   Classical ML Techniques : Regression, KNN, SVM, Decision Tree, Random Forest, PCA, XGBoost, Ensemble Learning, K-Means clustering DBScan Clustering,

4. Neural networks intuition
   Neurons, layers, activations (ReLU, softmax conceptually)
   Why deep learning works better for perception/language
   Classical DL Techniques : CNN, RNN, LSTM, GNN, RBM,  VAE, GAN, Transformers, Diffusion 
   Preventing Overfitting (Memorization) : Early Stop, Dropout, Weight Regularization, Data Augmentation (**Very important), Simplify Model, Batch Normalization
   Preventing Vanishing Gradient : Residuals (Skip Connections), Use RELU/LaekyRELU Activation Fn., Batch Normalization
   Bias/Vairance problem, Regularization and smooth learning
   Cross Entropy, Learning Rate Momentum
    
5. Hands-on (important for engineers)
   Train a simple model in Python (scikit-learn)
   Example:
    spam classifier OR house price prediction
    Show full pipeline in ~30–50 lines

   Outcome: They understand ML as a software system, not theory.
